# PianoTutor 打包说明

## 已打包结果

- **可执行程序目录**：`backend\dist\PianoTutor\`
- **主程序**：双击 `PianoTutor.exe` 即可运行（无黑框，纯 GUI）

## 使用

1. 将整个 **`dist\PianoTutor`** 文件夹复制到任意位置即可使用。
2. 若使用**多声部模式**：把 `CRNN_note_F1=0.9677_pedal_F1=0.9186.pth` 放到与 `PianoTutor.exe` **同一目录**下（当前打包未包含多声部依赖，仅单音模式可用；若需多声部请在本机安装 `piano_transcription_inference` 后重新打包）。

## 重新打包

在 **`backend`** 目录下执行：

```bat
build.bat
```

或手动：

```bat
cd backend
pip install pyinstaller
pyinstaller --noconfirm --clean PianoTutor.spec
```

输出仍在 `dist\PianoTutor\`。
