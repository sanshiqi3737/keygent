# Web 端自测清单（测试阶段）

前后端启动方式见根目录 **`如何运行.md`**。

## 1. 上传乐谱

- [ ] 选择 PDF + MusicXML（.musicxml / .mxl / .xml），点「上传」
- [ ] 出现 **乐谱 ID**，第 2 节技巧能加载（或提示无技巧）

## 2. 比对 — 录音

- [ ] 第 3 步选择 **mp3 / wav** 等录音，点「开始比对」
- [ ] 出现准确率、错音列表（数值是否合理另论）
- [ ] （可选）勾选「多声部」再试一次，不应 500（若缺模型可能 503，属依赖问题）

## 3. 比对 — MIDI（与标准 MusicXML 对齐时更易高分）

- [ ] 第 3 步选择 **.mid 或 .midi**（例如与当前谱对应的演奏 MIDI）
- [ ] 点「开始比对」，应 **成功**（不再出现仅因格式导致的 Internal Server Error）
- [ ] 勾选「保存练习记录」后，第 4 节能看到会话与概况更新

## 4. 近期练习概况

- [ ] 第 4 节进入页面或点「刷新概况」有 JSON 展示
- [ ] 勾选「仅统计当前乐谱」且已上传本曲时，统计范围符合预期

## 5. 练习 API 开关（可选）

- [ ] 设置 `ENABLE_PRACTICE_API=false` 重启后端后，`/api/practice/*` 与第 4 节应失败或报错
- [ ] 恢复默认后再次正常

---

**说明**：标准答案是 **MusicXML**，弹奏是 **MIDI** 时，时间轴与参考谱由不同来源产生，若未对齐可能出现大量错音；用于验证「流程通」时可优先使用与谱面一致的 MIDI 或同一工程导出的文件。
